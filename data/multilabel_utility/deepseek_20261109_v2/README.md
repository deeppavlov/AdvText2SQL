# Configuration utility v2 — согласованный сбор завершён

352 вопроса: **251 train + 101 dev**, с сохранением прежних DB/family splits.
Прежний test не включён. Исходные примеры не являются синтетикой.

| Файл | Назначение |
| --- | --- |
| `examples.jsonl` | Текст/evidence/шесть признаков схемы; качество конфигураций, unknown-маска и происхождение наблюдения |
| `conditional_pairs.jsonl` | Сопоставимые наблюдаемые маски, общий контекст и добавленные фичи; группы не раздаются отдельным флагам |
| `manifest.json` | Каталог, полнота train/dev, SHA источников/выходов и `ready_for_training` |

Переиспользованы **420 ответов**, дополнительно собраны **1174 ответа**.
Всего **1594 наблюдения** и **2856 условных пар** с полным покрытием train/dev:
пять конфигураций BIRD и четыре Ambrosia. Пары производны от исходных ответов,
а не являются отдельными независимыми экспериментами.
Метки `quality_targets` означают правильность всей конфигурации. Это не
независимые бинарные метки полезности отдельных фичей. `null` означает неизвестный
исход, а `loss_mask=false` исключает его из функции потерь.

**`ready_for_training=true`**: согласованная ограниченная очередь полностью собрана.
Старый датасет `deepseek_20261029/` не заменён. Классификатор v2 обучен отдельно:
`research_results/classifier_v2_training_20261109/`. По dev replay выигрыш над
рабочими опорами не получен; новая модель не включена по умолчанию.
Данные не доказывают причинный эффект: ответы взяты из отдельных запусков,
а часть train-наблюдений участвовала в адаптивном выборе инструкции MIPRO.

Ручные команды и протокол: [docs/25_classifier_refresh.md](../../../docs/25_classifier_refresh.md).
После новых запусков данные автоматически обновляются; отдельно офлайн:

```bash
bash local/run_classifier_v2.sh --export
```

Вход модели ограничен полем `inputs`. Benchmark/split/group ID и источники
предназначены для маршрутизации, разделения и аудита; эталонный SQL не входит в `inputs`.
