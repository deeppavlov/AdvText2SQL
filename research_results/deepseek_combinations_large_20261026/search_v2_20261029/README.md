Protocol, source hashes, grouped cohorts, explicit masks and historical per-question
controls are stored in `experiment.json`. Do not edit this file to change a run.
Comparisons and leaders are in `summary.md` / `summary.json`.

Default manual launch from the repository root:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File local/run_static_hybrid_search.ps1 --stage core
```

Runs only 14+32 and 32+35 on BIRD train 131 / Ambrosia train 136.
Repeat the command to resume; completed cases are skipped. Use `--dry-run` for local
validation, `--status` for local progress, `--scope full` for separate 241/227 runs.
The latter are exploratory, not an independent final test.

Results live under `<scope>/<case>/bird/` and `<scope>/<case>/ambrosia_227/`.
The `ambrosia_227` directory identifies the benchmark source, not the size of its
train/dev subset. Each case includes its actual dataset and question count.
